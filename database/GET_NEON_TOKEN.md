# 🔑 Como Gerar Auth Token do Neon

## Passo 1: Abrir Console do Neon
```
https://console.neon.tech
```

## Passo 2: Ir para Settings
1. Clique no **seu avatar** (canto superior direito)
2. Click: **Account Settings** ou **Settings**

## Passo 3: Encontrar API Keys
Procure por:
- **API Keys** ou **Developer Settings** ou **Integrations**

## Passo 4: Criar Nova API Key
1. Click: **Create API Key** (ou **New API Key**)
2. Dê um nome (ex: `copilot-setup`)
3. Click: **Create**

## Passo 5: Copiar Token
Você verá algo assim:
```
Key ID: xxx_yyy
Key: neon_xxx_xxxxxxxxxxxxxxxxxxx
```

⚠️ **Copie agora! Depois não poderá ver novamente!**

## Resultado Final
Você terá um token como:
```
neon_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```
